# ResearchReady Personas

ResearchReady Personas is a hands-on learning project for students preparing to
build AI-agent research portfolios for internships, including Microsoft Research
adjacent roles. It is not affiliated with Microsoft and does not assess, rank,
or recommend applicants.

The project teaches **persona building and user modeling** through a learning
assistant that adapts a technical learning path to a learner's explicitly shared
goals, experience, preferences, and consent choices.

## First learning question

> Can a transparent, editable learner model make hands-on AI-agent learning more
> relevant without storing sensitive or unnecessary personal information?

## Project principles

- Use fictional examples and self-reported learning information only.
- Never infer protected traits, mental-health status, or applicant quality.
- Let learners inspect, edit, and delete their own model.
- Separate temporary session context from durable, consented preferences.
- Measure learning support, not employability or hiring suitability.
